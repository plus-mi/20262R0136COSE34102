09. 과제 확인 방법

[저장소]
이름이 20262RCOSE32202인지 확인한다.
GitHub에서 공개 범위가 Public인지 확인한다.

[커밋]
git rev-list --count HEAD로 커밋 수가 10 이상인지 확인한다.
git log --oneline으로 각 커밋의 변경 목적을 확인한다.
git status로 기록하지 않은 변경이 남았는지 확인한다.
GitHub에서도 커밋 이력이 보이는지 확인한다.

[공개 내용]
프로젝트 #1 및 #2의 소스코드와 인증 정보가 없는지 확인한다.

[제출]
수업에서 제공한 Google Form의 실제 링크를 연다.
폼이 요청하는 이름, 학번, 이메일, GitHub ID 등의 정보를 정확히 입력한다.
폼 제출은 저장소 생성 및 push와 별도의 절차이다.
응답 제출 완료 화면을 확인한 뒤 과제 제출 완료로 판단한다.
